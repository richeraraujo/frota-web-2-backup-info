Integração privada de backup

Frota Web 2 Backups

Rotina administrada pelo proprietário para guardar cópias de um banco PostgreSQL no Google Drive, com verificação de integridade e testes periódicos de restauração.

Por que a integração acessa o Google Drive

O acesso permite criar os arquivos de backup e relatórios, conferir tamanho e integridade, baixar cópias para validar a restauração e mover cópias antigas para a lixeira conforme a retenção configurada.

A autorização usa o escopo drive.file, limitado aos arquivos criados pela integração ou selecionados explicitamente para ela. Não pede acesso geral a todos os arquivos da conta.

Uso privado

Esta integração é destinada à conta do administrador. Esta página apenas descreve seu funcionamento; não oferece cadastro, login público ou acesso aos backups.
