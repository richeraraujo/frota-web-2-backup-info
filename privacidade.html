Política de privacidade

Esta política descreve a integração privada Frota Web 2 Backups, administrada pelo proprietário identificado nesta página.

Dados acessados e finalidade

A integração acessa metadados e conteúdo dos próprios arquivos de backup e relatórios no Google Drive. Usa esses dados exclusivamente para armazenar cópias, verificar integridade, testar restaurações e aplicar a retenção definida pelo administrador.

O escopo Google drive.file limita o acesso aos arquivos criados pela integração ou selecionados expressamente para ela. Nenhuma permissão geral sobre todo o Drive é solicitada.

Armazenamento e processamento

As cópias e relatórios ficam nas pastas privadas do Google Drive do administrador. O processamento ocorre em um executor temporário do GitHub Actions. A autorização OAuth e a credencial do banco ficam em GitHub Actions Secrets no repositório privado da rotina. Arquivos temporários são removidos ao final da execução; os backups não são publicados como código ou artefatos públicos.

Google e GitHub processam os dados necessários para fornecer esses serviços. A rotina não vende dados, não os utiliza para publicidade e não os usa para treinar modelos de inteligência artificial. O acesso por pessoas depende das permissões que o administrador concede na conta do Drive e no repositório.

Retenção e controle

A configuração prevê 30 dias de cópias diárias e 12 meses de cópias mensais e relatórios. A limpeza move somente arquivos identificados como pertencentes à rotina para a lixeira. Backups manuais ficam fora dessa limpeza. O administrador pode alterar a retenção ou excluir arquivos diretamente no Drive.

A autorização pode ser revogada nas conexões da Conta Google. Revogar o acesso interrompe novos backups; não apaga automaticamente os arquivos já guardados. A rotina também pode ser desativada no GitHub Actions.

Contato

O responsável é o proprietário do perfil richeraraujo. A integração destina-se ao uso privado dessa conta.
